> 在 X（推特）上自动识别代币合约地址，点一下就出实时行情 + 风控卡片。
> Chrome 扩展（Manifest V3），免费、无登录、不连钱包。

## 这是什么

刷 X 的时候，经常有人发一串合约地址：

> 兄弟们，这个新币 CA：`0x6982508145454ce325ddbe47a25d4ec3d2311933` 冲不冲？

**装了这个扩展**，推文里的地址会变成**蓝色高亮**，点一下就地弹出卡片：

| 卡片显示 | 你看什么 |
|---|---|
| 代币名称 / 链条 / DEX | 确认是不是你要的那个币 |
| 当前价格 + 24h 涨跌 | 有没有已经被拉飞 |
| **池子深度** | 太浅的池子容易被砸盘 |
| FDV / 24h 交易量 | 判断热度真假 |
| 池子年龄 | 刚开盘几小时的币风险高 |
| **安全风控** | ✅ 正常 / 🚨 貔貅盘（能买不能卖）/ ⚠️ 高税收 |

**装之前**：复制地址 → 打开 DexScreener → 在 30 个池子里找 → 再开一个网站查貔貅 → 三个标签页。
**装之后**：点一下。

---

## 为什么它比别的工具准一点

一个币在 DexScreener 上可能有 **30 个交易对**。浅池子显示「高风险」，深池子显示「正常」——
**大多数工具返回的是第一个，也就是浅的那个**，风控结论直接是反的。

这个扩展**按流动性排序，永远取最深的池子**。实测 PEPE：取到 $23M 的池子，而不是 $500K（差 46 倍）。

另外两个细节：

- **防注入**：代币名是链上随便起的，可以带 `<img onerror=...>`。所有渲染走 `textContent`，不拼 HTML。
- **Solana 不误报**：交易哈希和 Solana 地址同形，所以先向 DexScreener 验证「这真是代币」才高亮。

## 安装（30 秒，不用商店）

**为什么不在 Chrome 商店**：上架需要 Google 开发者账号 + $5 + 人脸验证，暂时卡住了。
下面这个方式完全免费，效果一样。

1. 下载：[web3-twitter-radar-v1.4.1.zip](https://github.com/maomaoyu777/token-radar-release/releases/latest/download/web3-twitter-radar-v1.4.1.zip)
2. 解压到一个你找得到的文件夹（比如桌面）
3. 打开 Chrome，地址栏输入 `chrome://extensions/`
4. 右上角打开 **开发者模式**
5. 点 **加载已解压的扩展程序** → 选解压出来的文件夹
6. 打开 x.com，推文里的地址就是蓝色的了

也可以用 Edge（`edge://extensions/`，步骤一样）。

## 已知局限（说清楚，不吹）

| 情况 | 结果 |
|---|---|
| 推文正文里的完整地址 | ✅ 蓝色高亮，点一下出卡 |
| 地址在链接 URL 里（`dexscreener.com/ethereum/0x…`） | ✅ 链接后出现 ⚡ 按钮 |
| **X 的行情小卡里被截断的地址**（`$0.6982…1933`） | ❌ 认不到，请用手动查询 |
| 刚发币、还没有流动池的币 | ❌ 显示「未检测到活跃底池」 |
| Solana 貔貅检测 | ❌ 公开接口不支持，只能看流动性 |

**它不是投资建议工具。** 它只告诉你合约的数据，不告诉你该不该买。

## 技术栈

- Manifest V3，纯原生 JS，**无构建步骤、无依赖包**
- SPA 安全的 DOM 扫描：增量 MutationObserver + rAF 合并 + 单节点 try/catch
- 权限：`storage`（只存本地监控列表）+ 3 个 host，无 `tabs`/`cookies`/`<all_urls>`
- 数据来源：DexScreener（行情）+ Honeypot.is（EVM 合约模拟），都是公开只读接口

Privacy Policy

Web3 Token Radar · Last updated 2026-11-27 · Version 1.3.0

Short version: no account, no analytics, no telemetry, no server of our own. The only network requests are read-only calls to two public APIs, and they carry nothing but the token address you chose to look up.

What the extension does with data

Data Where it goes Why
Text of the X page you are viewing Stays in your browser Read locally to find 0x… and Solana addresses so they can be highlighted. Never transmitted or stored.
Token address you click or type Sent to api.dexscreener.com and api.honeypot.is To return price, liquidity, volume and contract-risk data.
Your IP address Implicitly visible to those two APIs Standard HTTP behaviour, outside our control.
Card data (price, liquidity…) In memory for 30 seconds To avoid duplicate requests when you re-open the same card. Cleared when the tab closes.

The extension writes to chrome.storage.local for one thing only: the watchlist you build yourself (≤20 addresses). Nothing else is stored, and nothing is ever synced or uploaded. It does not read other tabs, your history, your bookmarks or your clipboard. It cannot see or touch your wallet — it never asks for a wallet connection and contains no blockchain-writing code.

Third-party services

Two public, read-only APIs are contacted. Their own privacy policies apply to those requests:

  • DexScreener — dexscreener.com (market data)
  • Honeypot.is — honeypot.is (contract simulation for EVM chains)

No data is sent to the developer. There is no backend server.

Permissions, and why each one exists

Permission Reason
Content script on x.com and twitter.com To read post text on X in order to detect contract addresses.
Host access to api.dexscreener.com To fetch public DEX pair data for the address you clicked.
Host access to api.honeypot.is To run a public contract simulation (buy/sell tax, honeypot status).
storage To save the watchlist you build by clicking “Watch” on a card (up to 20 addresses). Stored locally only, never synced or uploaded, deleted when the extension is uninstalled.

The extension requests no other Chrome permissions — no tabs, cookies, history, <all_urls> or activeTab.

Remote code

All JavaScript ships inside the extension package. The extension does not load, evaluate or inject remote code, and does not use eval or new Function.

Children

The extension is not directed at children and collects no data from anyone.

Data deletion

Because no personal data is collected or stored by the developer, there is nothing to delete. To remove all local traces, uninstall the extension; its in-memory cache disappears with the tab.
